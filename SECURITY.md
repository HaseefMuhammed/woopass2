# Security Policy

## WOO PASS

WOO PASS is security-focused software developed by TEB Innovations.

We welcome responsible security research and vulnerability reports.

### Responsible Testing

Security testing must only be performed against systems and accounts
for which you have authorization.

Do not:

- access another user's vault;
- steal or expose credentials;
- destroy or modify user data;
- attack third-party infrastructure;
- deploy malware;
- perform denial-of-service attacks;
- intentionally harm users;
- publish weaponized exploit instructions.

### Vulnerability Reporting

If you discover a security vulnerability, please report it privately
to the WOO PASS maintainers.

Include:

- Description of the vulnerability
- Affected component
- Steps to reproduce
- Security impact
- Suggested fix, if available

Never include real users' passwords, private notes, tokens,
personal information, or other confidential information.

### Scope

This policy applies to WOO PASS and official infrastructure where
TEB Innovations has authorized security testing.

Third-party services remain subject to their own policies and terms.
